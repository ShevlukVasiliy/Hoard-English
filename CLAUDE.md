# Hoard — приложение для грамматики английского

Десктоп-приложение на Tauri 2 + React (Vite) + Bun и PWA для телефона из той же сборки. Работает автономно, ИИ в продукте не используется.

- Концепт: [CONCEPT.md](CONCEPT.md)
- План и статусы: [STAGE_PLAN.md](STAGE_PLAN.md)
- UX и визуальный язык: [UX.md](UX.md)

## Как работаем

### Stage plan — источник правды
- **Перед началом задачи** найди её в `STAGE_PLAN.md` и поставь `[~]`.
- **После завершения** ставь `[x]` сразу, не пачкой в конце.
- **Задачи нет в плане** — сначала добавь её в нужный стейдж, потом делай.
- **Отменённую задачу** не удаляй: помечай `[-]` с короткой причиной.
- Пункты плана — короткие действия, одно действие на строку.
- В работе одновременно — не больше одного-двух пунктов `[~]`.

### Продуктовые изменения
- Любое изменение поведения, экранов, контента или концепта записывай в «Журнал изменений» внизу `STAGE_PLAN.md`: `дата — что изменилось — почему`.
- Если изменение противоречит `CONCEPT.md`, обнови и концепт.
- Крупные продуктовые решения (новая фича, смена подхода, удаление функциональности) — сначала согласуй с пользователем, потом делай.

### Разработка
- Пакетный менеджер и раннер — только `bun` (не npm/yarn/pnpm).
- Перед тем как сказать «готово», проверь: `bun run typecheck`, для Rust — `cargo check` в `src-tauri`.
- Коммить логическими шагами, когда пользователь просит.

## Структура
- `src/` — React-интерфейс
- `src-tauri/` — Rust: окно, трей, автозапуск, уведомления, чтение Anki, файлы данных
- `shared/` — типы, логика и контент (уроки, тесты, словари)

## Данные
JSON-файлы в `~/.eng-teacher/` (в PWA — `localStorage` с теми же именами). У каждого файла ровно один владелец:
- **Приложение:** `events.json`, `progress.json`, `settings.json`, `anki-words.json`, `highlights.json`, `sync.json`
- **Фоновый поток Rust:** `reminder-state.json`

Не пиши в файл другого владельца.

**Журнал действий** (`shared/journal.ts`) — источник правды: прогресс, заметки и очередь Anki вычисляются из `events.json`. Новое действие пользователя — новый тип события, а не прямая правка `progress.json`. Событие хранит всё для пересчёта и не зависит от контента уроков.

**Синхронизация** (`shared/sync.ts`) — через secret-гист GitHub пользователя, своего сервера нет. В гисте каждое устройство пишет только свои файлы `ev-<устройство>-<месяц>.json`; словарь Anki выгружает только Mac. `sync.json` (токен, пароль) в гист не уходит.

**PWA** — та же сборка на GitHub Pages (`.github/workflows/pages.yml`, `BASE=/Hoard-English/`). Вне Tauri нет Anki, трея, автозапуска и напоминаний: такие места проверяют `inTauri`.

## Правила продукта
- **Без ИИ.** Нейросеть не используется: проверка — по эталонным ответам, уровень — по тестам.
- **База Anki** (`collection.anki2`) открывается только на чтение. Добавлять слова — только через AnkiConnect.
- **Язык ученика:** русский, испанский, немецкий, польский (`shared/i18n`). Интерфейс и теория A1–B1 — на родном, B2+ — на английском. Ловушки всегда на родном и написаны под его ошибки.
- **Контент других языков** — оверлей в `shared/lessons/l10n/<язык>`; русский текст в уроках — эталон. Меняешь русский — обнови оверлеи; `shared/l10n.test.ts` ловит непереведённое. Новые строки интерфейса — в `shared/i18n/ru.ts` и во все словари.
- **Структура урока:** теория → практика (случайная выборка из банка) → «История про язык».
- **Дизайн минималистичный:** без UI-библиотек, системные шрифты, светлая и тёмная тема.
- **Контент** не копирует защищённые авторским правом материалы. Для внешних данных (CEFR-J и др.) указывай лицензию и атрибуцию.
